# Public Repository Boundary

This repository is the public, review-ready snapshot of BIM Review Agent.
It intentionally contains the product source, deterministic rules, public prompts,
generated IFC fixtures, current UI evidence, and reproducible video source.

## Deliberate exclusions

- No recipient email, private delivery URL, browser session data, or API key.
- No Git history from the internal development repository.
- No third-party real-building IFC corpus with unclear redistribution terms.
- No original building-standard PDFs or complete OCR reproductions.
- No unlicensed or unused audio effect files.
- No machine-specific absolute paths or live deployment project identifiers.

The public IFC fixtures under `tests/fixtures/real_ifc/generated_issues/` are
generated by this project and are pinned by manifest hashes. Real IFC samples
used for internal regression testing remain outside this public snapshot.

The rule packs are deterministic demonstration policies. The repository does
not provide statutory certification, professional approval, or a license to
redistribute external standards or source models. Refer to the source authority
pages recorded by the rule documentation before using any rule in a real project.

The final demo video and generated MiniMax audio are delivered separately. The
repository keeps the generation script and timing metadata, but does not commit
API credentials or generated audio files.
